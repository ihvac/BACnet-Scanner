# BACnet Scanner 1.0.0 (beta)

> **This is a beta.** It is complete enough to use on real equipment, but it has not yet been through a season
> of daily work. Expect bugs. **If you hit one, please report it** — what you did, what happened, and what you
> expected. The status bar message has a "Copy" button, and the Log module has "Open the log folder": the
> current day's log file from there says more than anything else you can send.

A BACnet/IP browser and master: discovery (Who-Is, IP range scan, router discovery), the device and object
tree, properties, writing with priorities, live values over COV, schedule and calendar editors, alarms, trends,
a simple graphics editor, designation analysis, projects, EDE export and state snapshots.

No autotuner and no Saia — those are in **PID Autotuner**.

| Download | For |
|---|---|
| `BacnetScanner-1.0.0-x64.msi` | install for all users: Start menu shortcut, firewall rule for UDP 47808 |
| `BacnetScanner-1.0.0-x64-portable.zip` | unpack and run; all data stays in a `Data` folder beside the program |

Windows x64. The .NET runtime is included, nothing else has to be installed. On first start Windows asks about
firewall access — allow it for the network the devices are on (UDP 47808).

**Writing to a device.** Every write is confirmed first in a dialog naming the device and the value, read back
afterwards, and recorded in `audit.log`. A **read-only mode** refuses every write at the transport — worth
switching on before you connect to an installation you are only allowed to look at. Digital inputs are
read-only.

The packages are not digitally signed, so SmartScreen warns about an unknown publisher.

Press F1 for the built-in manual. The interface is Polish, English or German.

## Known limits of this build

- The graphics module is kept but no longer developed, and it has no background image.
- Creating a File object in a device (CreateObject) can be attempted but most controllers refuse it.
- `BacnetScanner.exe` physically contains the Saia, Modbus and tuning code, although it offers no way to reach
  any of it.
